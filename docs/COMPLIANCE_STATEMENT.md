# Compliance Statement

## 1. Executive Summary
SecureForge is designed to meet strict international standards for data sanitization and forensic data handling, ensuring that organizations can confidently use it for secure decommissioning of assets and legally defensible data recovery.

## 2. NIST SP 800-88 Rev. 2 (2025) Alignment
SecureForge aligns with NIST and IEEE 2883-2022 standards:
- **Clear:** Logical overwrite techniques (Zero fill, Random, DoD).
- **Purge:** ATA Secure Erase, NVMe Crypto Erase (Cryptographic Erase).
- **Destroy:** Not supported via software (requires physical destruction).
